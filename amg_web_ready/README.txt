AMG Quiz 2026 - GitHub Pages

1. Creeaza un repository public pe GitHub, de exemplu: amg-quiz.
2. Incarca fisierul index.html in repository.
3. Intra la Settings -> Pages.
4. La Source selecteaza Deploy from a branch.
5. Selecteaza branch-ul main si folderul / (root), apoi Save.
6. Dupa cateva minute, site-ul va fi disponibil la adresa afisata de GitHub.

Aplicatia functioneaza offline dupa ce pagina a fost incarcata, iar progresul este salvat local in browser.
